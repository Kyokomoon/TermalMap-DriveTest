# Модуль для генерации тепловой карты и покрытия базовой станции

Модуль позволяет обрабатывать данные о мобильной сети, представляя их в виде тепловой карты, а так же рассчитывать покрытие базовой станции
Так же реализовано деление полученных данных на тайлы
### Генерация тепловой карты
Данные беруться из БД Postgress, получение этих данных реализованно в src/getData.py, после чего полученные данные валидируются и с помощью формул 

$$ x = \left\lfloor \left( \frac{\text{lon} + 180}{360} \right) \cdot 2^{\text{zoom}} \right\rfloor $$

$$ y = \left\lfloor \left( 1 - \frac{\ln\left(\tan\left(\text{lat} \cdot \frac{\pi}{180}\right) + \frac{1}{\cos\left(\text{lat} \cdot \frac{\pi}{180}\right)}\right)}{\pi} \right) \cdot 2^{\text{zoom}-1} \right\rfloor $$

Определяется к какому тайлу относится каждая точка, после чего она помещается в список точек этого тайла
Когда все тайлы определены, процесс генерации разбивается на потоки, в каждом потоке отрисовывается свой тайл
В целом этап отрисовки выглядит следующим образом:
- Отрисовываются слои (RSRP, RSRQ, SNR, PCI_mod_3, PCI_mod_6) для всех операторов сразу
- Отрисовываются все слои для кааждого оператора по отдельности
Когда тайл готов, он сохраняется в свою папку

### Генерация покрытия базовой станции
Для этого используются формулы распространения, взятые из спецификации 3GPP, есть возможность отрисовать всенаправленную антенну

<img src = "/src/3.png">

многосекторную антенну

<img src = "/src/7.jpeg">

Так же реализована возможность учитывать потери на прохождение через здания
для этого используется алгоритм Брезенхэма, с его помощью определяется луч до каждого пискеля тайла и проверяется наличие зданий на его пути, после чего суммируются все потери
